## Building Solvequill

[Solvequill](https://www.solvequill.com), live in beta, turns a homework question into a short narrated whiteboard video lesson: the problem is solved step by step on the board while a voice explains each move.

Students type the question or upload a photo, screenshot or PDF. Every lesson comes with a summary, a quiz, practice problems and a chat about that solution. Mathematics, physics, chemistry and coding, in English and Turkish.

The code is private. Screenshots, the tech stack and what I am working on now are in the [Solvequill showcase](https://github.com/mirzaisi/solvequill-showcase).
